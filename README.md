# NoEdgeBall

Placar de beach tennis por voz — você canta o placar, o marcador acompanha.
Protótipo de validação antes do app nativo para Galaxy Watch.

## Publicar no GitHub Pages

1. Os cinco arquivos desta pasta vão na **raiz** do repositório:
   `index.html` · `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png`
2. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root)**
3. Em um ou dois minutos o app fica em `https://<usuario>.github.io/<repositorio>/`

## Instalar no celular

Abra o endereço no **Chrome**, menu ⋮ → **Instalar app** (ou "Adicionar à tela inicial").
Na primeira vez que tocar em *Escutar*, o Chrome pede o microfone — permita.

## O que funciona sem rede

O app, o placar e o histórico. O reconhecimento de fala do navegador precisa de internet.
